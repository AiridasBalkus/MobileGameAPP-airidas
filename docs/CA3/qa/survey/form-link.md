# Mino closed test: feedback form

**Form:** https://forms.cloud.microsoft/e/YYyjNvHK6G (Microsoft Forms, SETU account, anonymous, names not recorded)
**Title:** Mino closed test, build 0.8.0
**Also on:** Mino's About screen (text + "Give feedback" button)

## Fields (in order)
1. Device model and Android version (choice from device matrix + Other)
2. Build ID from the About screen (text)
3. Install: worked first time / needed help / failed (choice)
4. If failed, what did the phone say? (text, optional)
5. Minutes played (number)
6. Crash, freeze or "not responding" seen? none / freeze / crash / not responding (choice)
7. If yes: when, and what were you doing? (text, optional)
8. Feel 1 to 5 (Likert): smoothness, heat, battery drain, control responsiveness (5 = great / stayed cool / barely drained)
9. Loop 1 to 5 (Likert): I understood the goal; I wanted one more go; difficulty felt fair
10. One thing to fix (text)
11. One thing to keep (text)
12. Consent (required): anonymous responses used for a university project; no personal data collected

Tested on my own phone; test response deleted. Responses export to CSV for Async Pack 3 (due Sun 29 Nov 2026).
