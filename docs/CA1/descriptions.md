# Mino: Store descriptions (draft)

## Short description
Swipe between three lanes and dodge obstacles in a fast, offline endless runner

## Long description
Mino is a quick-reflex lane runner built for one thumb, the longer you run the higher the score! Swipe left or right, to switch between three lanes and dodge the obstacles rushing toward you. Simple to pick up, and it gets harder to keep up the longer you run.

**FEATURES**
- Three-lane swipe controls designed for one-handed portrait play
- Speed that ramps up the longer you survive
- Several obstacle types to read and react to
- Collectible pickups placed in risky lanes for extra points
- Score based on distance, with your high score to beat
- Haptic feedback on hits and pickups (can be turned off)
- Adjustable text size for readability
- Pause at any time; the game pauses itself if you switch apps or take a call
- Steady 60 fps on modern Android phones

**PLAYS YOUR WAY**
- Fully offline, no account or connection needed
- No ads
- No in-app purchases
- No personal data collected
